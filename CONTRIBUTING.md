# Contributing

Thanks for considering a contribution to Awesome Edge-First Inference.

## What belongs here

- Real, actively-maintained projects, SDKs, and serving frameworks relevant to running inference on-device or at the edge.
- Primary sources (official docs/repos) rather than secondary blog posts when linking a tool.
- Honest tradeoffs — this list is a decision guide, not a marketing page. If something has sharp edges, say so.

## What doesn't

- Dead or archived projects (unless kept in a clearly marked "historical" section for context).
- Duplicate entries already covered by a more canonical project in the same category.
- Pure opinion pieces with no concrete tool/resource attached.

## How to submit

1. Open a PR adding your entry to the relevant category, alphabetized within the category.
2. One line description, present tense, no marketing superlatives ("blazing fast", "revolutionary").
3. If proposing a new category, explain briefly in the PR description why it doesn't fit an existing one.
4. If you're disputing a claim in the Decision Heuristics or "When You Actually Need the Cloud" sections, open an issue with your reasoning/evidence rather than editing it directly — those sections represent a considered position, not just a list.

## Code of conduct

Be respectful. Disagree with claims, not people.
